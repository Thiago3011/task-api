# Task API

Uma API simples para gerenciamento de tarefas, desenvolvida com Python, FastAPI e SQLite.

## Objetivo

Este projeto tem como objetivo praticar os fundamentos do desenvolvimento de APIs com Python, evoluindo em pequenas etapas.

## Tecnologias

- Python
- FastAPI
- SQLite

## Como executar

As instruções de instalação e execução serão adicionadas conforme o projeto evoluir.

## Funcionalidades planejadas

- Criar tarefas
- Listar tarefas
- Consultar uma tarefa
- Atualizar tarefas
- Excluir tarefas

## Status

Em desenvolvimento.
